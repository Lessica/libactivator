# Hardware/System Action 对齐表

本文是 Hardware/System actions 的 listener 粒度工作队列。状态只表示当前对齐审计进度，不把现有实现或旧 master 代码默认视为已对齐。每完成一行，都必须补 1.9.13 IDA、1.9.13 package/resource、旧 master 对照或真机验收依据，并同步更新 `LISTENER_HANDLED_BASELINE.md` / `LEGACY_REVERSE_ENGINEERING.md` 中会影响后续判断的结论。证据必须写清层级：旧 master 对照、resource metadata、通用 `_LASimpleListener` gate、selector 级 IDA、现代 handled 准则和真机验收不能互相替代；只有声明范围内的返回值和现代差异都被覆盖时才能标 `aligned` 或 `modern-aligned`。不得为了 handled 对齐改变既有现代实现方案；方案不变时能对齐的返回语义才落代码；旧实现和现代实现差异较大时，应从旧实现总结策略并制定现代 handled 准则，再按准则实施。

## 状态

| 状态 | 含义 |
| --- | --- |
| `todo` | 尚未完成 1.9.13 语义核对，不能声称已对齐。 |
| `partial` | 已有部分依据或部分 listener name 验收，但同一实现单元仍有未核对分支。 |
| `aligned` | 当前实现、handled 语义、测试口径和落盘依据已完成对齐。 |
| `modern-aligned` | 旧实现与现代实现方案差异较大；已从旧实现提炼现代 handled 准则，并按该准则完成当前实现与依据落盘。 |
| `blocked` | 需要设备能力、私有 SPI 决策或 owner 确认后才能继续。 |
| `metadata-only` | 当前只保留资源，不注册 runtime listener object。 |
